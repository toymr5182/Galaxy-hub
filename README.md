# Galaxy-hub

Minecraft AFK bot manager (web dashboard + mineflayer).

Features kept: bot manager/dashboard, reconnect, chat/commands, inventory view, auto-join server menu, auto commands, **auto-eat**.
New: **Server Login (password screen)** – answers the 1.21.6+ server "Dialog" password screen automatically.
Removed: old /login-on-spawn, mining / chopping / farming / chest deposit / pathfinder tasks.

Run: `npm install && npm start`
